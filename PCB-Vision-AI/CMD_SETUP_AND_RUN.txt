PCB VISION AI - WINDOWS CMD SETUP AND START

PROJECT FOLDER
cd /d "C:\Users\hp\Desktop\Projects\DL\PCB-Vision-AI"

ONE-TIME SETUP (Python 3.11)
py -3.11 -m venv venv
call venv\Scripts\activate.bat
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

START THE DASHBOARD
cd /d "C:\Users\hp\Desktop\Projects\DL\PCB-Vision-AI"
call venv\Scripts\activate.bat
python -m streamlit run app.py

Open the local URL printed by Streamlit, usually http://localhost:8501.
Keep the CMD window open while using the dashboard. Press Ctrl+C in that
window to stop Streamlit.

The trained model is loaded from the project's models folder. Normal dashboard
use does not retrain the model or require a separate evaluation command.
