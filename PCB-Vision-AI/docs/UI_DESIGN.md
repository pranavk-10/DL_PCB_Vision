# Inspection workstation design

The design-taste-frontend app-screen run dealt **Framed sheet**, seed
**478161225**, for a developer workstation. A pale PCB green frame surrounds a
white inset sheet; probability data and region boxes carry the green accent.
The pipeline diagram is an explanatory drawing, not a dataset image.

The inspection screen answers: which image regions need examination? Home
answers whether the project has data, a completed model, and evaluated results.
Performance answers which classes the selected trained model handles well.
The circuit mark comes from PCB pads and conducting traces. Source images are
shown only after the user supplies them. Missing metrics remain missing.

The dealt remote IBM Plex fonts cannot be downloaded in this environment.
`Segoe UI`, available on Windows, is the deliberate offline font fallback.
No sample inspection statistics, fabricated boards, or fake predictions are used.
The app inspector and screenshots require a running Streamlit application;
see VALIDATION_REPORT.md for the actual execution status. No visual score is
claimed without screenshots. Native Streamlit navigation provides its mobile fold.
